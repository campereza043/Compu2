◆ Mueva_r()

void Bola::Mueva_r ( double  dt)

Actualiza la posición (Paso 1 de Velocity-Verlet). r(t+dt) = r(t) + v(t)dt + 0.5*a(t)dt^2 Pero en Velocity Verlet estándar se suele hacer: r += v * dt + 0.5 * a * dt^2 O el esquema: v(1/2) = v + 0.5*a*dt; r(new) = r + v(1/2)*dt. Aquí usaremos métodos granulares para que Sistema controle el orden.
