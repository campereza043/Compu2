# Motor Molecular: Flashing Ratchet

Implementación en C++ de un modelo de Flashing Ratchet siguiendo diseño POO.

## Estructura
- `src/`: Código fuente C++.
- `include/`: Archivos de cabecera.
- `scripts/`: Visualización en Python.
- `results/`: Salida de datos.

## Compilación y Ejecución
Requiere CMake y compilador C++.

```bash
mkdir build
cd build
cmake ..
make
./simulacion
